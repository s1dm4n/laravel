# Проверка локального стенда

Дата: 18 ноября 2026 года.

## PHPUnit

10 тестов, 52 утверждения, ошибок нет.

- Письмо ожидает запуска database-очереди.
- Обработчик удаляет успешно выполненное задание.
- Читатель не может создать статью.
- Повторяющийся адрес не получает два письма в одном выполнении.
- Database-уведомления доступны только владельцу и отмечаются прочитанными.
- Кеш корректно читается повторно и сбрасывается при создании статьи и модерации комментария.
- Статистика учитывает записи текущего дня и успешные просмотры.
- API поддерживает токены, CRUD, проверку входных данных и ролей.

## Браузер и SMTP

Проверены создание статьи через web-форму, получение онлайн-оповещения в уже открытой второй вкладке, приём письма локальным Mailpit, список уведомлений читателя и уменьшение счётчика при прочтении. Планировщик запущен через schedule:run; письмо статистики принято Mailpit.

После изменения оформления повторно получено событие о новой публикации. У читателя счётчик уменьшился с 2 до 1 при открытии нового уведомления. Оставшееся уведомление относилось к предыдущей тестовой публикации.

Результаты относятся к локальному стенду. Облачный Pusher, внешняя почта, нагрузочное испытание и развёртывание на публичном хостинге не проверялись.
